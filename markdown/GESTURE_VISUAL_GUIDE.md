## 侧面视角对比

### Gun vs Thumbs Up（容易混淆，需要注意）

**Gun (侧面看)**:
```
      │
      │ <- 拇指
   ═══╧═══════ <- 食指
   █████

食指水平向前
拇指垂直向上
形成L形
```

**Thumbs Up (侧面看)**:
```
      │
      │ <- 拇指
   ═══╧═══
   █████

只有拇指向上
其他完全握紧
没有L形
```

**区分关键**：Gun 有明显的食指向前伸出！

## 采集角度建议

### 每个手势都要采集的角度：

```
        0° (正面)
           │
           │
   -45° ───┼─── +45°
           │
           │
        侧面

建议采集5个角度：
1. 正面 (0°)
2. 左斜 (-30°)
3. 右斜 (+30°)
4. 上仰 (+20°)
5. 下俯 (-20°)
```

### 特殊注意的手势：

**Gun (需要更多角度)**：
- 正面：L形最明显
- 侧面：容易与 thumbs_up 混淆，要多采集
- 45°斜角：最佳角度

**Rock vs Call Me（需要区分）**：
- 正面：都是两个突起，但位置不同
- Rock：对角（食指+小指）
- Call Me：两端（拇指+小指）
