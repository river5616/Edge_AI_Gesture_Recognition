# debug_inference.py - ONNX 对比功能使用指南

## 功能概述

`debug_inference.py` 现已增强，支持实时对比 STM32 和 PC 端的推理结果：

- **STM32 推理**：通过串口接收 STM32 发送的图像和识别结果
- **PC 端推理**：使用 ONNX Runtime 在 PC 上对同一图像进行推理
- **实时对比**：自动比较两端的识别结果，标记一致/不一致
- **详细统计**：生成包含对比数据的报告和可视化图表

## 安装依赖

确保已安装 `onnxruntime`：

```bash
pip install onnxruntime
```

如果未安装，脚本仍可运行，但不会进行 PC 端对比。

## 基本使用

### 1. 默认使用（自动启用 ONNX 对比）

```bash
python debug_inference.py --port COM17 --frames 50
```

脚本会自动查找 `gesture_model.onnx` 文件并启用对比功能。

### 2. 指定 ONNX 模型路径

```bash
python debug_inference.py --port COM17 --frames 50 --onnx-model path/to/your/model.onnx
```

### 3. 禁用 ONNX 对比

如果不想使用对比功能，只需不安装 `onnxruntime` 或指定不存在的模型路径：

```bash
python debug_inference.py --port COM17 --frames 50 --onnx-model none.onnx
```

## 使用场景

### 1. 验证模型转换准确性

**目的**：确认 PyTorch → ONNX → X-CUBE-AI 转换后模型行为一致

**操作**：
```bash
python debug_inference.py --port COM17 --frames 100
```

**判断标准**：
- 一致率 > 95%：转换成功，行为基本一致
- 一致率 80%-95%：可能存在轻微数值误差（可接受）
- 一致率 < 80%：转换可能有问题，需检查

### 2. 诊断识别错误根源

**目的**：当 STM32 识别错误时，判断是模型问题还是部署问题

**分析**：
- **STM32 错误，PC 正确** → 可能是：
  - X-CUBE-AI 转换问题
  - 预处理不一致
  - 量化误差

- **STM32 和 PC 都错误** → 可能是：
  - 训练数据问题（分布偏移）
  - 图像质量问题
  - 光照/对比度问题

- **STM32 正确，PC 错误** → 很少见，可能是：
  - ONNX 导出问题
  - 预处理差异

### 3. 置信度分析

**目的**：对比 STM32 和 PC 的置信度差异

**查看**：
- `summary_plot.png` 中的第 6 个图（置信度散点图）
- 如果点都集中在 y=x 线附近 → 置信度一致
- 如果点偏离 y=x 线 → 可能存在量化或转换问题

## 故障排除

### 问题 1：ONNX 模型未加载

**现象**：
```
⚠️ ONNX 模型文件不存在: gesture_model.onnx
○ ONNX 对比模式：未启用
```

**解决**：
1. 检查 `gesture_model.onnx` 是否在当前目录
2. 使用 `--onnx-model` 参数指定正确路径

### 问题 2：ONNX Runtime 未安装

**现象**：
```
⚠️ 警告: onnxruntime 未安装，将无法使用 PC 端对比推理
   安装命令: pip install onnxruntime
○ ONNX 对比模式：未启用
```

**解决**：
```bash
pip install onnxruntime
```

### 问题 3：ONNX 推理失败

**现象**：
```
✗ ONNX 推理失败: [错误信息]
```

**可能原因**：
- ONNX 模型损坏或版本不兼容
- 输入形状不匹配
- 预处理错误

**解决**：
1. 重新导出 ONNX 模型
2. 检查模型输入形状是否为 (1, 1, 64, 64)
3. 确认预处理与训练时一致

## 技术细节

### 预处理流程（与 STM32 完全一致）

```python
# 1. 归一化到 [-1, 1]
normalized = (image.astype(np.float32) / 255.0 - 0.5) / 0.5

# 2. 调整维度为 (1, 1, 64, 64)
input_tensor = normalized.reshape(1, 1, 64, 64).astype(np.float32)

# 3. 运行推理
outputs = onnx_session.run([output_name], {input_name: input_tensor})
```

### 置信度说明

- **输出类型**：原始 logits（未经 softmax）
- **范围**：可以是任意实数（通常在 -5 到 10 之间）
- **意义**：值越大表示该类别的置信度越高
- **选择**：选择 9 个输出中最大值对应的类别

### 一致性判定

只要 STM32 和 PC 预测的类别 ID 相同，就视为一致，不考虑置信度差异。

## 命令行参数完整列表

```bash
python debug_inference.py \
    --port COM17 \                    # 串口号（必需）
    --baudrate 921600 \               # 波特率（默认 921600）
    --frames 50 \                     # 采集帧数（默认 100）
    --save-dir debug_inference \      # 保存目录（默认 debug_inference）
    --onnx-model gesture_model.onnx   # ONNX 模型路径（默认 gesture_model.onnx）
```
